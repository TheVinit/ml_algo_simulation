Hidden Markov Model: Mathematical Symbols Reference

SymbolDescriptionSource / Derivation
i, jState indices (i = antecedent state, j = successor state).Hidden state space S
tDiscrete time step index (t = 1, 2, ..., T).Observation sequence length T
t − 1, t + 1Previous / Subsequent discrete time steps.Temporal lattice indexing
otObserved emission symbol at time step t.Sequence token O[t]
πiInitial state probability: P(q1 = Si).Initial probability vector π
AijState transition probability: P(qt = Sj | qt-1 = Si).State transition matrix A
Bj(ot)Emission probability: P(Ot = ot | qt = Sj).Emission probability matrix B
αt(j)Forward probability: P(o1, ..., ot, qt = Sj | λ).Dynamic Programming recursion (sum-product, left-to-right)
βt(i)Backward probability: P(ot+1, ..., oT | qt = Si, λ).Dynamic Programming recursion (sum-product, right-to-left)
δt(j)Viterbi score: highest probability of a single path ending at qt = Sj.Dynamic Programming recursion (max-product)
ψt(j)Viterbi backpointer: argmax index of state at t-1 yielding maximum δt(j).Viterbi argmax trace for backtracking
ΣSummation operator over candidate paths.Total path probability integration
maxMaximization operator over candidate paths.Optimal path selection
